# PRD：图书短视频选题与生成平台

版本：v0.2；日期：2026-10-28；定位：供评审的需求草案。

## 1. 产品定位

面向个人及小型自媒体创作者的图书短视频研究与创作工作台。先由产品发起人自己测试，再邀请 5–20 位创作者封闭试用。用户输入书名、ISBN 或商品链接后，查看有证据的商品表现与相关账号/视频，提炼可复用的表达方式，再生成与指定图书事实相符的原创带货短视频草稿。系统保留数据来源、分析依据、人工审核和生成版本，让「为什么选这本书、为什么采用这个脚本」可以追溯。

核心闭环：**选书/选商品 → 收集证据 → 评估机会 → 提炼风格特征 → 生成脚本/分镜 → 审核 → 渲染视频 → 创作者手动发布并挂小黄车 → 复盘**。

## 2. 用户与任务

| 角色 | 主要任务 | 首期权限 |
| --- | --- | --- |
| 你（首批测试者） | 验证选书、研究、生成、发布和挂车的完整流程 | 管理自己的数据与任务 |
| 小型自媒体创作者（封测） | 选择自己可推广的图书，生成并编辑短视频 | 只访问自己的项目与素材 |
| 平台管理员（封测阶段由你兼任） | 邀请/停用试用者，配置数据源、预算，查看失败任务 | 管理连接与审计，不默认读取他人私有素材 |

## 3. 关键概念与指标

| 名称 | 定义 | 展示规则 |
| --- | --- | --- |
| 实际销量/销售额 | 经授权的商家订单数据，按退款、时间和归因口径计算 | 必须显示店铺范围、统计期、更新时间；无权访问时不展示 |
| 平台展示销量 | 官方页面或获许可数据服务展示的字段 | 与实际销量分开，写明原始口径和来源 |
| 热度信号 | 可合法取得的点赞、评论、分享、播放、搜索热度、排行等 | 只能表示关注度或内容表现，不能写成销量 |
| 内容表现 | 同平台、同时间窗、同样本范围内的互动/播放等指标 | 显示采集时间、样本量和缺失字段；避免跨平台直接比较绝对值 |
| 风格特征 | 对开场、叙事结构、节奏、画面、字幕、情绪和 CTA 的抽象标签 | 给出参考证据与人工可编辑的解释，不复制原视频素材或逐字文案 |
| 机会评分 | 对证据质量、热度、竞争强度、图书适配度的内部排序 | 显示各分项、权重、缺失项；标记为辅助判断 |

## 4. 核心场景

1. **找值得做的书**：运营输入主题或图书清单，按合法数据源查看相关商品与内容表现，筛出候选书。
2. **找有效的表达方式**：查看相关账号的视频样本、内容结构和表现，收藏可借鉴的特征，形成风格卡片。
3. **给指定书生成带货视频**：填写目标读者、平台、可推广商品、卖点、禁忌与 CTA；系统依据已核实事实和风格卡片生成多版脚本、分镜、配音与成片。默认 9:16、20–45 秒。
4. **发布与复盘**：创作者逐项确认事实与素材许可，导出 MP4、标题/简介和挂车核对卡；在抖音/快手客户端自行发布并添加商品。后续手动录入或经授权回传表现数据。

## 5. 功能范围

### P0：可验证的最小闭环

| 模块 | 需求 | 验收要点 |
| --- | --- | --- |
| 图书项目 | 输入书名/ISBN/商品链接；补充作者、版本、受众、原创荐书理由、禁用表述、目标商品 | 同书不同版本可区分；事实有来源或人工确认状态；商品与视频所讲版本一致 |
| 数据源管理 | 接入已获授权/许可的数据源；支持人工录入和 CSV 导入 | 显示授权范围、字段覆盖、最近同步、失败原因；禁止无凭据的假数据 |
| 研究台 | 商品、账号、视频的列表与详情；筛选时间、平台、类目；收藏参考 | 每个数字可点开来源、时间窗和口径；缺失值显示「未取得」 |
| 风格卡片 | 为参考视频提炼开场方式、结构、节奏、视觉、语气、CTA | 每条特征可编辑/删除；关联证据；不直接复用原视频内容 |
| 创作任务 | 指定书、目标平台、20–45 秒、风格卡片，生成 2–3 个原创脚本方案 | 以创作者原创观点为核心；事实有依据；支持逐段改写 |
| 人工审核 | 创作者本人确认脚本、商品一致性和所有素材许可后才允许最终渲染 | 留存确认人与版本；不能确认时返回修改 |
| 视频草稿 | 默认用文字动效、自制图形、核实可商用的 TTS 与模板输出 9:16 MP4 | 不依赖书封/内文/商品图；可预览、下载；失败可重试 |
| 挂车交付包 | 导出标题、简介、封面文案、目标商品 ID/链接和发布检查卡 | 明示由用户在平台内发布并添加商品；发布前核对账号资格和商品可推广状态 |
| 成本与任务 | 查看任务状态、阶段耗时、模型/媒体调用费用估算 | 任务可取消；用户能看到失败阶段和可操作建议 |

### P1：验证后扩展

- 更多获许可数据源与跨平台对比；自有账号表现回传；A/B 版本与复盘。
- 多尺寸、批量任务、品牌模板、团队审批配置。
- 文生视频镜头作为可选素材供应商；生成质量、成本和版权机制需单独验证。
- 在平台授权与审核允许时，评估发布和挂车接口；首期仅导出，由用户在平台内完成发布及挂车。

### 暂不承诺

- 任意关键词的全平台历史视频搜索、任意竞品账号的真实销量、任意账号的后台播放/转化数据。
- 自动下载并复用第三方视频、未经授权使用书封/内页/商品图/音乐、模仿特定真人声音/肖像、直接复刻竞品文案。
- 自动判断某书一定会卖好或生成后一定能获得流量。

## 6. 关键流程与规则

**研究流程**：建立项目 → 选择可用数据源/导入数据 → 系统标准化并去重 → 展示商品/账号/视频证据 → 用户收藏样本 → 生成可编辑风格卡片。

**创作流程**：核对图书事实、商品版本与可推广状态 → 输入原创观点和创作 Brief → 生成 2–3 版脚本 → 编辑选版 → 生成分镜/素材计划 → 本人审核 → 渲染 → 导出交付包 → 在平台内发布并手动挂车 → 记录反馈。

**失败处理**：接口权限不足时显示不可用原因和替代输入方式；事实缺来源时标红并阻止直接引用；素材缺授权时不可进入渲染；商品 ID/版本未核对时不能标记为「可发布」；长任务可继续/重试，不重复扣费或生成重复成片。

## 7. 体验与质量目标（建议验收值）

| 目标 | 首期验收建议 |
| --- | --- |
| 可追溯 | 所有展示的外部指标保留来源、时间窗、采集时间与口径；抽样核对准确 |
| 事实可靠 | 成片涉及作者、书名、内容、价格等断言须有来源或人工确认；无来源不自动编造 |
| 创作效率 | 使用已备齐事实和素材的项目，5 分钟内得到可编辑脚本草案（排除第三方服务故障） |
| 可控生成 | 每次任务可查看状态；审核前不产生最终成片；同一版本可复现输入参数 |
| 挂车一致性 | 导出包中的图书版本、视频描述和拟挂商品一致；用户在平台发布前再次确认 |
| 安全 | 封测用户数据相互隔离；密钥仅服务端存储；授权撤销后停止同步并按协议处理数据 |

## 8. 依赖、风险与待决策

最关键依赖是数据权利。抖音开放平台的关键词视频搜索要求特定权限和用户授权，并仅返回最近 1 天数据；官方场景说明还将关键词限制在与自身业务相关的词，不适合被当作通用竞品历史搜索。具体可参见[接口说明](https://open.douyin.com/platform/resource/docs/openapi/search-management/keywords-video-list/keywords-video/)和[场景限制](https://open.douyin.com/platform/resource/docs/ability/search-management/video/)。因此 P0 的竞品研究须依靠**明确许可的数据服务、人工整理的链接/样本或其他经核准的渠道**，可用程度取决于实际合同。

首期决策：本人测试后邀请少量创作者；默认 20–45 秒竖屏文字动效视频；没有图书及外部素材授权时不使用封面、内文、商品图、竞品片段和商业音乐。荐书文案必须基于可核实事实与创作者原创观点。著作权法对复制、摄制、改编、网络传播等权利有规定；[国家版权局公布的著作权法](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)可供核对。具体素材是否可用，以权利证明和平台规则为准。

挂车方案：抖音官方商家教程描述在 App 发布页「添加标签/添加商品」的操作；[官方教程](https://school.jinritemai.com/doudian/web/articlev0/aHxFNtFoQJ6E)可供核对。快手官方发布接口存在可选的 `merchant_product_id` 字段，但需相应发布授权；[接口文档](https://open.kuaishou.com/platform/openApi?group=GROUP_OPEN_PLATFORM&menu=20)。抖音公开的视频发布接口列出的锚点类型为小程序、游戏、POI；不能据此认定支持电商小黄车自动挂载，见[接口文档](https://open.douyin.com/platform/resource/docs/openapi/video-management/douyin/create/create-video)。因此首版由创作者在各平台手动发布和挂车。

仍需外部验证：试用账号的图书带货资格与商品可推广状态、可用数据授权/合同、TTS 商用条款、部署地区与月度预算。
