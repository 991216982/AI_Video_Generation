# 数据接入、指标口径与使用边界

版本：v0.2；调研日期：2026-10-28。接口开放范围、权限、配额和协议会变化，开发前应以申请结果及最新官方文档复核。

## 1. 数据源分层

| 层级 | 典型内容 | 可用于什么 | 前置条件 |
| --- | --- | --- | --- |
| A：自有/获授权商家 | 本店商品、订单、退款 | 实际销量、销售额、转化复盘 | 商家授权及相应字段权限 |
| B：自有/获授权创作者 | 自有账号作品和视频数据 | 自有内容表现、脚本复盘 | 创作者 OAuth 和相应权限 |
| C：获许可的第三方服务 | 合同约定的跨账号/商品样本、估算指标 | 竞品研究、趋势观察 | 核对来源、再使用范围、存储与展示许可 |
| D：人工输入 | 用户粘贴链接、上传 CSV、填写观察笔记 | 先做研究与生成闭环 | 记录操作者、出处和可使用权利 |

**原则**：缺少 A/C 层时，产品仍可做书籍事实管理与创作，但不显示「畅销书排行榜」或「竞品真实销量」。C 层的估算必须标注为估算，不能与 A 层订单数据混排成一个指标。

## 2. 平台能力核验

| 平台 | 当前官方可见能力 | 设计结论 |
| --- | --- | --- |
| 抖音开放平台 | OAuth 授权；视频/粉丝等能力按 scope 申请；特定视频数据接口仅查询 token 对应用户上传的视频；关键词搜索需特殊权限且最近 1 天、限定自身相关词 | 适合自有/授权账号数据和符合条件的品牌相关监测；不能据此承诺通用竞品库 |
| 抖店开放平台 | 自用型/工具型应用；商品、订单等商家业务接口 | 适合授权店铺经营数据；并非全平台图书销量接口 |
| 快手开放平台 | 网站应用 OAuth；能力和数据披露受平台授权范围约束 | 先确认具体 scope、应用审核与合同，再定义可展示字段 |
| 快手电商开放平台 | 授权应用可接商品、订单等商家接口 | 适合授权店铺；不推断任意竞品真实交易 |

官方依据：[抖音权限表](https://open.douyin.com/platform/resource/docs/accession-guide/type-and-permission/)、[抖音特定视频数据接口](https://open.douyin.com/platform/resource/docs/openapi/video-management/douyin/search-video/video-data/)、[抖音关键词场景](https://open.douyin.com/platform/resource/docs/ability/search-management/video/)、[抖店应用类型](https://op.jinritemai.com/docs/guide-docs/127)、[快手网站应用授权](https://open.kuaishou.com/platformDocs/develop/web-app)、[快手电商开放平台](https://open.kwaixiaodian.com/)。

## 3. 统一数据契约

所有外部记录统一带：`platform`、`source_type`、`source_id`、`source_url`、`owner_scope`、`license_id`、`observed_at`、`collected_at`、`metric_window_start/end`、`metric_definition`、`raw_snapshot_ref`、`confidence`、`expires_at`。缺失字段保持 null，并记录原因；不填 0。

核心实体：

- `BookEdition`：ISBN、书名、作者、出版社、版次、封面权利、事实材料。
- `ProductListing`：平台商品 ID、店铺 ID、对应图书版本、价格、上下架状态。
- `CreatorAccount`、`ContentItem`：账号与内容元数据；仅存许可范围内的字段。
- `MetricObservation`：指标名、值、单位、统计期、来源、采集时间、估算标识。
- `Evidence`：一个结论所引用的原始记录/页面/人工笔记及使用许可。
- `StyleCard`：抽象风格标签、描述、证据 ID、人工修订版本。
- `CreativeProject`、`ScriptVersion`、`Asset`、`RenderJob`、`ReviewDecision`：创作与审核链。

数据标准化先按 ISBN/版次匹配书，再按平台原生 ID 匹配商品和内容。跨平台同书聚合仅在书籍版本明确时进行；同名书不可自动合并。指标聚合必须先过滤相同平台、口径、时间窗和商品范围。

## 4. 排序和分析口径

初版「值得研究」排序采用可解释的分项：数据可信度、近 7/30 天内容表现、同类竞争强度、图书与目标受众匹配度。权重在后台可配置，默认只用于候选排序，不命名为销量预测。样本不足或指标缺失时显示「证据不足」，不硬排绝对名次。

账号特色提炼只输出抽象模式，例如「前 3 秒提出反常识问题」「章节式字幕」「读者痛点→书中观点→行动建议」。每个判断至少关联一个参考内容，界面给出样本数和人工可改的解释。禁止自动导入原视频画面、音频、完整字幕作为可复用素材。

## 5. 授权、安全与生命周期

1. 每个连接记录授权主体、scope、有效期、用途、应用 ID；密钥与 refresh token 仅在服务端加密保存。
2. 连接器按平台限流、重试与配额运行；原始响应单独存放并限制访问，业务表只保留必要字段。
3. 授权撤销、合同到期或删除请求触发停止同步、清理/保留判定和审计；最终规则按各平台协议与合同配置。
4. 导入数据在界面标注「用户提供」；有版权或个人信息风险的内容须先确认使用权。
5. 发布前另做版权/事实/广告表达审核。书封、试读、音乐、人物肖像、声音和第三方视频均需要独立使用依据。

首批试用者分别记录自己的平台账号和拟推广商品。平台不代替创作者申请橱窗/带货资格，也不将「有商品链接」等同于「可挂小黄车」。针对商品保存平台商品 ID、书籍版本、推广资格的人工确认时间；发布包在界面提示商品与视频内容必须一致。快手的[挂载规则](https://edu.kwaixiaodian.com/rule/web/detail?id=uG9iB2uu9B)明确要求视频主推商品与锚点商品相符。

### 无图书/素材授权时的默认素材策略

| 素材 | 首版默认处理 |
| --- | --- |
| 书名、作者、ISBN、出版社等基础事实 | 核实来源并注明版本；文案由创作者原创撰写 |
| 书封、内页、试读文字、出版社商品图 | 未取得明确许可则不上传、不嵌入成片；平台原生商品卡由平台展示 |
| 竞品视频、截图、字幕、音乐 | 只做有权范围内的研究引用；不作为成片素材 |
| 画面 | 自制排版、图形、字幕动效；后续引入明确可商用素材并保存许可凭据 |
| 声音 | 使用已核实可商用的通用 TTS；不克隆真人声音；许可未核实前可使用创作者自行录音 |

系统对每个成片素材保存 `origin`、`license_basis`、`permitted_uses`、`proof_ref`、`expires_at`。权限不明按不可用处理，不以「网上能看到」作为商用许可。评论性使用是否属于法律例外取决于具体情形，首版不把该例外作为自动批量复用素材的依据；见[著作权法](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)。

快手开放平台协议明确限制未经许可的自动化抓取与超范围使用；见[开发者服务协议](https://open.kuaishou.com/platform/protocol)。设计上不以绕过登录、反爬或批量抓取作为数据方案。

## 6. 数据接入的阶段门槛

进入开发前，逐个平台形成一张「字段 × 来源 × 权限 × 允许用途 × 保留期限 × 成本」清单。若没有跨账号合法来源，首版研究台定位为**自有/获授权内容数据 + 人工竞品研究**，且 UI 明示数据覆盖范围。首位测试者可先用人工输入验证创作闭环，但对外封测前要完成用户数据隔离和素材许可检查。
