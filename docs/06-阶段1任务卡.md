# 阶段 1 首轮任务卡

基线提交：`1354984`。共同输入：`docs/01-PRD.md`、`docs/03-系统架构.md`、`docs/05-开发计划与多Agent执行.md`、`AGENTS.md`、`packages/contracts/openapi.yaml`、`events.schema.json` 与 `examples/`。所有实现只针对人工输入和虚构样例；遇到契约缺项，向集成负责人提交建议，不自行修改 `packages/contracts/`、根配置、`main.py` 或 `worker.py`。共享工作区由集成负责人提交 Git。

## W1-A：领域/API

- **目标**：让单用户以人工输入创建具体图书版本、拟挂商品、证据和创作项目；保存脚本版本、运行/审核状态与发布包元数据，所有私有记录服务端按 `owner_user_id` 隔离。
- **允许修改**：`apps/api/src/book_video/api/`、`core/`、`domain/`、`persistence/`、`connectors/manual/`、`apps/api/migrations/`、`apps/api/tests/agent_a/`。
- **输入**：OpenAPI 的 Book/Evidence/Promotion/CreativeProject/Script/Run/Review/Render/PublicationPackage 字段、状态迁移表、人工样例。阶段 1 本地身份可固定为开发用户，但由服务端赋值。
- **输出**：领域校验、持久化（开发环境 SQLite 可以起步，迁移必须可复现）、对应 `/api/v1` 路由、运行事件按序持久化和读取、供集成负责人接线的领域服务入口。异步生成和渲染仅通过抽象提交钩子/状态接口协作，不能在 HTTP 请求里直接执行耗时生成。
- **验收**：`python -m pytest apps/api/tests/agent_a -q`；用 TestClient 从图书/商品/证据创建到项目与脚本版本的请求响应符合契约，未确认资格、事实和素材时拒绝审核通过或发布包就绪；相同幂等键不产生重复 run/render。
- **不做**：平台 OAuth/爬取、真实销量、LangGraph、视频合成、前端、共享契约变更。

## W1-B：前端

- **目标**：让本人在浏览器完成图书/拟挂商品录入、Brief、脚本查看与改稿、运行状态和人工审核、发布包下载及手动挂车核对。
- **允许修改**：`apps/web/`（包括该目录的测试和锁文件）。
- **输入**：冻结 OpenAPI、SSE 事件、虚构样例；API 基址通过 Vite 环境变量设置。
- **输出**：React + TypeScript 页面和薄 API 客户端；空态与错误态明确显示“未取得授权数据/商品未核实”；发布包只提示用户在平台客户端手动发布和挂车。前端不得自行判定商品可推广或绕过审核状态。
- **验收**：在 `apps/web/` 运行 `npm run typecheck` 与 `npm run build`；页面可用样例流程演示录入、脚本版本、审核与发布包，API 不可用时有可读提示。
- **不做**：修改后端、共享契约、自动发布/挂车、任何第三方素材显示或抓取。

## W1-C：生成链

- **目标**：由已核实事实和原创观点形成两版可编辑脚本，支持人工审核暂停/恢复，并把审核通过的一版渲染为 1080×1920、20–45 秒文字/自制图形 MP4。
- **允许修改**：`apps/api/src/book_video/workflows/`、`media/`、`tasks/`、`apps/api/tests/agent_c/`。
- **输入**：共享契约的 CreativeProject、BookEdition、PromotionCandidate、ScriptVersion、AssetRights 和 RunEvent 字段。生成入口接受集成层提供的纯数据快照与持久化/事件回调，不直接依赖 Agent A 的未定实现；输出脚本、状态事件、渲染结果元数据给集成层保存。
- **输出**：最小 LangGraph 图（可先用确定性本地文本模板，无外部模型密钥）、审核中断与恢复、幂等的任务入口、FFmpeg 文字图形渲染清单与视频质检。声音许可未确认时默认静音，不能使用书封/内文/商品图/第三方视频或音乐。
- **验收**：`python -m pytest apps/api/tests/agent_c -q`；审核前不得渲染；同幂等键重试不会重复生成有效成片；有 FFmpeg/ffprobe 的环境用 `ffprobe` 验证 MP4 尺寸、时长和视频流。
- **不做**：API 路由、数据库模型、前端、平台数据连接、共享契约或根依赖配置改动。缺少依赖或 FFmpeg 时明确报告给集成负责人，由其调整配置/环境。

## 集成负责人接线与验收

集成负责人独占 `main.py`、`worker.py`、`pyproject.toml`、共享契约、跨模块测试与 Git 提交。按 API → 生成链 → 前端顺序接线；运行迁移、领域/API、生成状态/幂等、前端构建和虚构样例端到端测试。无真实可推广商品或已核实声音许可时，只能报告本地演示闭环，不能声称平台发布验收完成。
