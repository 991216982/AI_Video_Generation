## 当前边界

- Web 初始处于“虚构演示”，不会请求 API、生成真实商品资格或假发布结果。切换“API 工作区”后才调用本地 API。
- 本地 API 使用固定开发用户和 SQLite；封测前需真实登录、用户隔离与更稳健的任务队列。运行/渲染领取在 SQLite 中原子化，LangGraph `MemorySaver` 仍只在当前 worker 进程有效；等待审核期间重启 worker 后不能恢复图 checkpoint。
- 当前成片只用自制文字/图形，默认静音。未核实商用 TTS、创作者自录音输入、真实书封/商品图等许可，不纳入本地样例。
- 发布包始终标记 `needs_manual_checks`。创作者必须自行在抖音/快手后台核对带货资格和真实商品，再于平台客户端发布及手动挂车；本仓库未执行或验证这些平台动作。
- 契约后续可补“商品创建后人工资格更新”“账号资格记录”“项目列表/刷新恢复”接口；这些缺口不阻断当前虚构样例，但会影响真实试用便利性。修改共享契约仍由集成负责人统一处理。
