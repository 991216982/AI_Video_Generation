- G1 复核：远端 `main` 为上述 SHA；对应 [CI 运行](https://github.com/991216982/AI_Video_Generation/actions/runs/40829772969) 成功，精确 head SHA 一致；FFmpeg/ffprobe 和中文字体环境的完整 API 测试为 **26 passed、0 skipped**。真实账号与商品的人工验收待办仍在[执行计划](./08-阶段1后完整执行计划.md#真实使用的人工验收待办账号持有人执行)中，尚未完成。
- G2 改动文件：`packages/contracts/openapi.yaml`、`packages/contracts/events.schema.json`、`packages/contracts/README.md`、三个 `packages/contracts/examples/` 样例和 `scripts/verify_stage0.py`。OpenAPI 从 v0.1.0 升为 v0.2.0，新增 8 个操作：图书/项目游标列表、项目工作区详情、拟挂商品人工资格更新、run/render 取消和重试。事件新增 `run.cancel_requested`、`run.retry_requested` 和重试轮次；样例全为虚构数据。
- G2 语义：列表按当前 owner 和 `(created_at, id)` 倒序；游标绑定 owner 与过滤条件。资格只能由创作者后台人工核对后记录，带 revision、核对人和时间，撤回后重算后续审核/发布包检查项。取消分排队直接终止与执行中请求取消；重试只针对失败任务，保留 ID 与不可变输入，轮次加一。重复幂等键同请求只能产生一次迁移。
- 兼容影响：v0.1 的路径和请求字段保留。旧客户端若忽略新增响应字段，原流程可继续；但旧服务端不支持 8 个新操作。v0.2 的 `PromotionCandidate`、`Run`、`RenderJob` 有新必填响应字段，历史数据要迁移为初始 revision/attempt 1、取消请求时间 null。严格枚举 SSE 类型的消费者需接受两个新事件。前端新功能须与 v0.2 服务端一起部署；当前代码在 W2 集成前仍是 v0.1 实现。
- G2 验证：`python scripts/verify_stage0.py`、`python -m pytest apps/api/tests -q -ra`（26 passed、0 skipped）、`npm run typecheck`、`npm run build` 均通过。G2 的 CI 以分发基线提交对应的远端运行结果为准。

## 所有 Agent 的执行规则

先读 `AGENTS.md`、`docs/README.md`、`docs/08-阶段1后完整执行计划.md`、`packages/contracts/README.md`、本文件及分发消息中的完整基线 SHA。仅修改卡片列出的路径；共享目录、根配置、`apps/api/src/book_video/main.py`、`worker.py`、`integration.py`、`apps/api/pyproject.toml` 与 `apps/api/tests/integration/` 由集成负责人处理。三位 Agent 共享同一工作目录，不重置、清理或提交 Git；不修改其他 Agent 的文件。遇到跨模块接口或依赖缺口，报告原因、建议字段与兼容影响，由集成负责人决定并修改共享文件。所有测试报告写明通过、失败、跳过数量与实际运行命令；不把 skipped 当成媒体测试通过。

仅使用人工输入或已获明确授权的数据；测试书、商品和账号均标记为虚构演示。未经许可的封面、内文、声音和其他素材不入片；不抓取平台数据、不自动发布或挂车，不把人工记录当作平台认证结果。

## W2-A：领域/API 与持久化

- **目标**：关闭浏览器后能按当前 owner 找回图书和项目，读回完整工作区；人工核对拟挂商品；可靠地取消和重试 run/render。
- **允许修改**：`apps/api/src/book_video/api/`、`core/`、`domain/`、`persistence/`、`connectors/manual/`、`apps/api/migrations/`、`apps/api/tests/agent_a/`。其中不存在的目录可在归属范围内创建。
- **输入**：冻结的 v0.2 `openapi.yaml`、`events.schema.json`、虚构样例，现有 SQLite/领域/API 实现；分发基线 SHA。
- **交付**：实现 `listBooks`、`listCreativeProjects`、`getCreativeWorkspace`、`updatePromotionEligibility`、`cancelRun`、`retryRun`、`cancelRender`、`retryRender`；owner 隔离、稳定分页和过滤游标；资格 revision 冲突与撤回；状态迁移、幂等键冲突、同 ID 重试轮次和历史保留；历史行迁移。为生成链暴露持久化的领取、取消确认和恢复所需领域接口，并向集成负责人说明调用方式。审核和渲染必须重新检查当下资格。
- **自验**：在仓库根目录运行 `python -m pytest apps/api/tests/agent_a -q -ra` 与 `python scripts/verify_stage0.py`。测试覆盖创建后重新连接数据库读回全部版本、owner 隔离、游标与过滤、资格撤回/并发 revision、重复取消和重试不产生双份记录、已成功或已取消任务拒绝重试。报告通过/失败/跳过数。
- **不做**：修改 worker、编排/媒体、前端、共享契约、根配置或真实平台连接器；不自行提交 Git。

## W2-B：前端工作区续用

- **目标**：用户能从 API 列表返回历史项目，刷新后继续审核或查看成片，明确处理资格更新、取消和失败重试。
- **允许修改**：`apps/web/`，含前端测试与 `apps/web/package-lock.json`。
- **输入**：冻结的 v0.2 OpenAPI/样例，现有前端与已记录的虚构演示流程；分发基线 SHA。
- **交付**：图书/项目列表、搜索和分页；按 `getCreativeWorkspace` 重开项目并恢复精确脚本版本、run、render 和发布包状态；资格人工核对与撤回 UI，展示 revision 冲突；取消/重试及 SSE/轮询进度，清晰空态和 API 错误；演示数据与真实工作区有明确标识。用户输入的资格核对说明只作为人工记录展示。
- **自验**：在 `apps/web/` 运行 `npm run typecheck` 和 `npm run build`；用浏览器手动走「创建 → 刷新 → 从列表重开 → 继续审核」及 API 断开提示。若加入自动前端测试，运行其命令并报告通过/失败/跳过数；手动检查记录实际结果和环境。
- **不做**：修改后端、共享契约或根配置；不接平台账号、不自动发布/挂车；不自行提交 Git。

## W2-C：生成链恢复与媒体幂等

- **目标**：待审核 run 在 worker 进程重启后仍能从持久 checkpoint 继续；重复恢复或渲染只有一个有效结果，取消能阻止后续副作用。
- **允许修改**：`apps/api/src/book_video/workflows/`、`media/`、`tasks/`、`apps/api/tests/agent_c/`。
- **输入**：冻结的 v0.2 事件与 run/render 状态语义、现有 LangGraph/FFmpeg 实现、A 所报告的领域持久化接口；分发基线 SHA。跨模块接线由集成负责人负责。
- **交付**：持久 checkpoint 的创建/定位/恢复接口，重启新进程后复用同一 run；重复恢复不追加第二份有效脚本版本/事件；render 领取与完成过程遵守取消、同 ID 重试和幂等，避免第二个有效 MP4；审前渲染继续拦截。若需新增 Python 依赖或数据库迁移，只向集成负责人提交具体建议，不改 `pyproject.toml` 或 A 的迁移目录。
- **自验**：在仓库根目录运行 `python -m pytest apps/api/tests/agent_c -q -ra`。新增跨进程暂停/恢复、重复恢复、重复渲染、取消中断和审前渲染测试。运行 `ffmpeg -version`、`ffprobe -version`，并用 `ffprobe` 检查测试生成 MP4 的尺寸、时长和流；媒体测试必须 0 skipped。报告命令与通过/失败/跳过数。
- **不做**：修改 API/领域/数据库模型、worker/集成接线、共享契约、根配置；不使用未授权媒体或声音；不自行提交 Git。

三卡返回后由集成负责人按 A → C → B 核对接口与接线，维护共享文件和端到端测试，执行[计划中的 W2 集成验收](./08-阶段1后完整执行计划.md#2-w2自用可靠性与可恢复)。这不授权开始 W3。
