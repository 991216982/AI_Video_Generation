## 已知边界

- v0.2 为兼容旧请求，API 的 `PromotionCandidateCreate` 仍可直接接受带时间和说明的 `manually_confirmed`，但该创建请求没有 `confirmation_basis` 字段。W2 前端已统一走“先未核实、后 PATCH”的流程；旧 API 创建语义留待下一次契约变更明确，不能据此声称平台已核实资格。
- 运行中任务的恢复 lease 默认 300 秒；worker 在任务执行期间突然退出时，可能需要等 lease 过期才能被另一进程重领。待审核 run 的新进程恢复不依赖该等待。
- 真实账号的图书带货资格、商品 ID 与版次、本人录音或商用配音许可、平台客户端手动发布和挂车仍为[人工验收待办](./08-阶段1后完整执行计划.md#真实使用的人工验收待办账号持有人执行)。没有这些输入，本记录不表示真实平台发布验收完成。
