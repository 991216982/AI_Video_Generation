日期：2026-10-29。W2 起点为 `main` 的 `c6f3e3eb215453ed9093145041d5f1d10a0b4151`（工作区干净）；`8e17dc6` 到该提交仅增加 W2 复核/G3 计划文档。**本轮只冻结契约和任务卡，W3 代码尚未实施，当前运行 API 仍为 v0.2。** G3 源契约为 [`packages/contracts/openapi.yaml`](../packages/contracts/openapi.yaml)、[`events.schema.json`](../packages/contracts/events.schema.json)，迁移与兼容说明在[契约 README](../packages/contracts/README.md)。分发时以包含本文件的 G3 冻结提交 SHA 为准，不从本文件的 W2 起点重新实现。

G3 变更：创建拟挂商品只能为 `unverified`；旧式创建即确认在 v0.3 返回 422，确认必须经现有 PATCH 并提供本人账号后台核对依据。事实修订按版次、键和修订号追加；本人录音经受控上传、许可声明与服务端校验后才能引用；模型结果与脚本版本关联，费用按实际调用唯一记录。仅新增可选语气指令，复用已有 Brief 与事实出处字段。事件增补生成结果/失败/成本 ID，样例全部为虚构数据。`python scripts/verify_stage0.py` 为契约检查；G3 不宣称运行 API 已完成这些端点。

## W3-A：事实、音频许可、成本 API

**目标**：把 G3 的事实修订、拟挂商品创建限制、本人录音元数据/受控上传、生成与费用只读查询实现到服务端。先读 `AGENTS.md`、本文件、契约 README/OpenAPI/事件/样例与 W2 测试。使用分发时的 G3 冻结 SHA。

- **只可修改**：`apps/api/src/book_video/api/`、`core/`、`domain/`、`persistence/`、`connectors/manual/`、`apps/api/migrations/`、`apps/api/tests/agent_a/`。
- **输入/接口**：`PromotionCandidateCreate`、`PromotionEligibilityUpdate`、`BookFactRevisionRequest`、`AudioAssetUpload`、`GenerationResult`、`ModelCostRecord`、`RenderCreate.audio_asset_id`；所有新 ID 为服务端分配，所有私有读取按 owner 过滤。
- **交付**：拒绝旧式创建即确认（422 `validation_error`，包含传入确认依据或时间的情形），保留 PATCH 人工确认；迁移旧事实为 revision 1，追加事实修订历史并做冲突检查；受控音频上传核对 SHA-256、真实格式、时长、文件大小、所有者与许可有效期；提供模型结果与实际费用的 owner 范围查询及唯一约束。历史未经可审计确认依据的候选商品按契约降为未核实，不能静默保留为已认证。持久化结构与 C 协作时只通过冻结字段或报告集成负责人处理跨模块接线。
- **自验**：`python -m pytest apps/api/tests/agent_a -q -ra`。覆盖创建即确认拒绝、PATCH 确认、事实来源/修订冲突、跨 owner、无许可/过期音频、错误摘要、重复费用、历史迁移。报告通过/失败/跳过数与迁移结果。
- **不做**：改契约、根配置、`main.py`、`worker.py`、`integration.py`、集成测试、前端或生成链；不接平台数据，不上传真实录音或未授权素材，不自动挂车。

## W3-B：创作前端

**目标**：让本人按冻结 v0.3 契约录入创作参数、比较和改稿、选择已许可本人录音，查看费用与失败原因。先读上述基线和契约。

- **只可修改**：`apps/web/`，包括前端测试及 `apps/web/package-lock.json`。
- **输入/接口**：复用 `target_audience`、`target_platform`、`desired_seconds`、`original_angle`、`prohibited_claims`、事实出处；仅增加 `tone_instruction`。使用事实修订、脚本版本/生成结果、音频资产和费用 GET；创建候选商品始终 `unverified`，确认只用 PATCH。
- **交付**：两版结构化脚本对比与逐段改稿，清楚标出所选审核版本和事实修订；本人录音上传/选择、许可和到期提示；静音选择、生成失败原因和实际/未知费用展示；成片预览与人工发布检查。API 工作区与虚构演示数据继续明显区分，刷新后版本/费用一致。
- **自验**：在 `apps/web/` 运行 `npm run typecheck`、`npm run build`；浏览器手动走虚构项目的录音选择、两版对比、改稿和刷新流程，附截图或可复查记录。旧式创建请求必须在前端消失，但仍以服务端拦截为准。
- **不做**：改后端、共享契约或根配置；不在浏览器伪造平台资格或以客户端路径给 worker；不接平台数据、未授权素材或自动挂车。

## W3-C：模型与音频生成链

**目标**：按 G3 结果/费用/音频契约生成原创脚本与带本人录音的文字动效视频，保留 W2 审核恢复和幂等。先读上述基线和契约。

- **只可修改**：`apps/api/src/book_video/workflows/`、`media/`、`tasks/`、`apps/api/tests/agent_c/`。
- **输入/接口**：消费服务端提供的精确事实修订、已人工确认候选商品、权利允许的 `audio_asset_id` 与私有媒体句柄；写 `GenerationResult`、`ModelCostRecord` 与事件。不得信任客户端 `AssetRights.allowed`，不得接受客户端本地文件路径。
- **交付**：可替换模型适配器和确定性无密钥假实现；两版结构化原创脚本，事实与禁用表述检查；生成结果/失败稳定原因码，实际调用唯一费用记录，重试不重复记费；合法本人录音与视频合成，静音时无音轨；旧暂停/恢复、取消和渲染幂等保持有效。外部模型只在条款、费用和密钥配置明确后启用；CI 不调用外部服务。
- **自验**：`python -m pytest apps/api/tests/agent_c -q -ra`；实际用 `ffprobe` 验证 1080×1920、20–45 秒、本人录音时有音轨/静音时无音轨，媒体检查 **0 skipped**。覆盖缺许可、事实无来源、错误输出、重复调用/重试和 worker 恢复。
- **不做**：改 API、数据库迁移、共享契约、`main.py`、`worker.py`、`integration.py` 或跨模块测试；不接平台数据、未授权素材或自动挂车。
