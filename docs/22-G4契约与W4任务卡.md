## 2. G4 契约变更要点

1. **指标证据（`MetricObservation`，`/metrics`）**：从旧 `Evidence.metric_*` 扁平字段拆为独立可追溯记录。`basis` 分四类：`authorized_order_sales`（授权订单实际销量，唯一可称实际销量）、`platform_listing_display`（页面展示值/档位）、`third_party_or_manual_estimate`（第三方/人工估算）、`engagement_signal`（播放/点赞等热度），外加回填用 `legacy_unclassified`。有数值必须带同 owner 证据、口径定义和观察时间窗；缺失为 `value=null + missing_reason`，**禁止写 0 冒充未知**；展示档位走 `value_text`，不参与数值排名。可比性限定同平台、对象范围、指标、单位、口径与时间窗；证据不足显示“未取得/证据不足”，不强行排名。
2. **内容参考（`ContentReference`，`/content-references`）**：只保存有权使用的链接、最小元数据、抽象观察笔记、授权范围与使用依据及证据关联。`material_statement` 固定声明不存第三方原视频/音轨/封面/商品图/完整字幕；未授权媒体与完整字幕不得成为成片素材。链接不等于授权。
3. **风格卡（`StyleCard`，`/style-cards`）**：只表达有证据支持的抽象特征，特征关联证据与样本数，`abstract_only=true`。无证据只能为草稿/待审，不得标 `approved`；人工修订走 `PATCH` + `expected_revision`，冲突 409，人工修订不被工作流输出覆盖。
4. **CSV 导入（`/imports`、`/imports/preview`、`/imports/{id}`、`/imports/{id}/confirm`）**：预览不落库 → 人工映射 → 确认写入；UTF-8 BOM、大小/行数上限、公式注入转义；行级诊断（行号、字段、稳定错误码、级别）；版次按 ISBN+版次匹配，同名异版不自动合并；`on_duplicate` 去重，同键重放可重复，同键异请求 409；部分失败逐行记录，作业状态 `applied/partially_applied/failed`。
5. **分页/过滤/错误码**：新列表沿用 v0.2 游标分页与 owner 隔离；非法游标 422 `invalid_cursor`；错误正文 `ApiError(code, message, request_id, details)`。导入作业级错误码：`import_preview_expired`、`import_file_too_large`、`import_too_many_rows`、`import_mapping_invalid`（422）、`import_already_applied`（409）。
6. **事件判断**：本轮**不新增 SSE 事件**。CSV 导入在请求/响应内同步完成（行数有上限，行级结果在响应体），研究与风格卡是人工驱动、不在 run 生命周期内；W4-C 提炼结果在既有确定性流程内消费。若 W4 集成后确有后台长任务进度需求，再由集成负责人走契约变更增补事件，`events.schema.json` 的 v0.3 事件集合本轮保持冻结。
7. **迁移默认值**：旧带指标的 `Evidence` 回填为 `legacy_unclassified` + `legacy_backfill=true` 的 `MetricObservation`，`confidence=null`，缺失原因沿用原值；重新核实前不参与排名。旧数据不被默认为授权数据或已核实资格。v0.3 旧路径与请求字段全部保留，新响应字段可被旧客户端忽略；新端点需前后端同版本部署。

## 3. 样例与隐私边界

`packages/contracts/examples/g4-research.json` 与 `research-import-fixture.csv` 均为虚构演示数据：书名、商品、账号、链接、数值与 ID 全为虚构；无真实账号、密钥、平台抓取结果、未授权素材或未经核实销量。授权订单样例数值是演示计数，不代表真实销量。CSV 样例覆盖 UTF-8 BOM、空值/缺失原因、非法数值、公式前缀、重复 ISBN、同名异版、不同时间窗与坏时间戳。
