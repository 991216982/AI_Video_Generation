# W4 众测产物集成与修复记录

日期：2026-11-03。分支：`codex/integrate-w4-crowdtest`。起点：`e475a95`（G3）。本记录描述本地代码集成与虚构数据验证，不表示真实平台账号、商品资格、销量或成片质量已经验收。

## 1. 选择与边界

本轮核对 copse、spume、bough、skerry、sedge 五份众测产物和此前的 ATIF 评测记录。它们是同一 W4 任务的替代实现，不能整体叠加：OpenAPI、领域服务、前端入口及迁移文件会相互覆盖。选择 **bough 的 v0.4 G4/W4 实现作为接线基底**，因为它同时提供共享契约、迁移、A/B/C 三部分代码和跨模块集成测试；再对发现的行为缺口做本地修复。未把任何模型自述的“通过”当作当前仓库的验收结果，所有数字以下方本地命令为准。

只接入 W4 人工研究台：证据与指标、内容参考、CSV 导入、风格卡及证据化抽象风格在原创脚本中的应用。没有接入 G5、平台抓取、自动发布/挂车、第三方音视频素材或 V0 视频质量专项。原工作区未提交的 `docs/README.md`、`docs/14–21`、`docs/22-G5…` 和 `scripts/render_*` 属于既有并行工作，保持原状；本分支提交时应显式列文件，不包含这些内容。

## 4. 兼容、迁移与剩余验证

- v0.3 旧客户端可继续调用既有端点；新研究台需前后端同版本部署。旧 Evidence 指标回填后口径为 `legacy_unclassified`，不能被自动解释为授权订单销量。迁移文件为 `apps/api/migrations/006_w4_research.sql`。
- `authorized_order_sales` 当前依赖录入者提供同 owner 证据、订单口径定义与时间窗。系统能校验记录完整性，不能独立鉴别商家授权真伪；真实销量结论须由账号/数据权利人核实原始订单权限后人工验收。
- 内容参考只保存最小元数据、链接、抽象笔记与使用依据。用户填写的权利依据仍需人工审查；不得把记录了链接理解为取得视频、音频、字幕或图片的使用许可。
- 初始集成时通过的是本地自动化与烟测。浏览器控制工具曾在 Windows 沙箱初始化时退出，初始集成未声称界面验收通过；后续使用隔离的 Edge 自动化完成研究台交互走查，见第 6 节。真实 CSV 样本（脱敏且有权使用）、多用户部署环境与真实发布前检查仍待各自验收。视频质量另列专项；当前产品主线为 20–45 秒图书带货视频，儿童动物故事保留为后续功能线。
