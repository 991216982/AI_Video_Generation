## 已确定的产品决策

1. **用户**：本人单用户验证 → 5–20 位小型自媒体创作者封闭测试；先做轻量账号隔离，不预建复杂商家 SaaS 功能。
2. **挂车**：首版导出视频、标题、简介、商品核对卡，创作者在抖音/快手发布时手动挂车；后续有权限再评估自动发布和挂车。
3. **视频**：首版做 9:16、20–45 秒的原创脚本 + 文字动效/自制图形 + 可商用 TTS + 模板合成；文生视频镜头放到后续试验，不作为首版必需能力。
4. **素材**：目前没有图书封面、内文、商品图、竞品视频、音乐及真人肖像/声音的使用授权。首版默认禁用这些资产；可在取得明确许可后逐项启用。作品以原创评论/荐书理由为核心。

## 仍需验证的外部条件

- 你和试用者各自的抖音/快手账号是否具备图书带货资格，拟挂商品是否可推广；具体准入以账号后台为准。
- 是否有创作者/店铺授权或已签约的数据服务；没有时不能承诺全平台竞品销量或任意账号完整流量。
- TTS、音乐、图片及后续 AI 视频供应商的商业使用条款和费用；未核实前只使用自制文字/图形与有许可的声音。
